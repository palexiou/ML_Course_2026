## Open and use the deck

Open [index.html](index.html) in a current browser. It uses a fixed 1920×1080 stage, scaled and letterboxed, with a local font and no build step. Keep the repository layout for assets and practical links. If using HTTP, serve the repository root.

- Arrows, Space and Page Up/Down navigate; Home/End jump to the ends. Swipe and mouse wheel also navigate.
- Keys 1–4 or the day selector jump to a day; the slide selector jumps by title. Stable links include `#day-3` and `#day-1-slide-29`; global `#slide-12` links also work.
- **N / Notes** opens detailed explanations, questions, expected answers and transitions. Escape closes notes or editing.
- **E** or the top-left edit area edits text and autosaves in this browser. Browser edits are drafts: reconcile accepted wording into repository source. Long edits need a layout check.
- **More → Save HTML** exports a copy; keep it in `slides/` beside `assets/`. More also provides fullscreen; printing produces one slide per page without notes.
