# Vague prompt

> Can you build the best model to predict promoters from these DNA sequences and explain the biology?

Before revealing the specification, identify what is missing: simulation versus real biology, prediction target, independence unit, split policy, permitted inputs, metric and threshold, comparison baseline, computation budget, output schema, reproducibility, and evaluation boundary. “Best” does not define an experiment. This prompt is authored teaching material; no response to it is claimed here.
