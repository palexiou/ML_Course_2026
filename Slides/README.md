# Course presentations

Open [index.html](index.html) to choose a day. Each `Day_N/presentation.html` contains only that day's content, with inline code and font for offline viewing. Linked notebooks and teaching resources use the repository layout. Keep exported HTML beside its day's presentation for those links.

- Arrows, Space, Page Up/Down and swipe/wheel navigate; Home/End jump within the day. The slide selector jumps by title.
- Keys 1–4 or the day selector open another day. New opening hashes use `#day-1-intro-welcome` through `#day-1-intro-discussion`; the [story](Day_1/story.md#1-course-and-ml-introduction--025) lists all titles/anchors. Section 2 starts at `#day-1-dna-section` (slide 25); the [story](Day_1/story.md#section-2) lists its 18 new anchors. Old Section 2 hashes `#day-1-slide-13`–`#day-1-slide-22` resolve to matching new concepts; later source anchors redirect to their matching new concept; the course index routes earlier day/global hashes.
- **N / Notes** opens explanations and transitions; Escape closes notes or editing. **E** edits text in the browser. **More → Save HTML** exports edits; **Print** prints the day's slides without notes. Reconcile accepted wording into repository source.

[Day 1 story](Day_1/story.md) is the active narrative source, with visible-content summaries and speaking notes for every reviewed section. [Teaching preferences](../docs/course-wiki/teaching-preferences.md#style-approved--2026-11-03) and the [logistic style reference](Day_1/logistic-style-reference.html) define the approved style: one short title, one focal visual, blue/orange contrast, generous space, and numerical provenance in notes.

**Day 1 is implemented for review: 112 slides**, comprising 24 + 18 + 16 + 16 + 20 + 16 section slides and two ten-minute break slides. Sections 1/2 are preserved. Sections 3–6 include score/sigmoid, downhill loss, threshold/ROC/PR and tree-path interactions; the aligned notebook has guided checkpoints for all four. Start at [Section 3](Day_1/presentation.html#day-1-lr-section), [Section 4](Day_1/presentation.html#day-1-metrics-section), [Section 5](Day_1/presentation.html#day-1-trees-section) or [Section 6](Day_1/presentation.html#day-1-explain-section). Old later-day-one source anchors redirect to the corresponding new concepts. Days 2–4 retain their earlier design.

Rebuild Sections 3–6 with `python tools/build_day1_slides.py`; it preserves the first 42 opening records and reads detailed notes from `Day_1/story.md`. Figure source and inline interaction source live under `tools/`. Empirical figures use the source-bound [current local validation record](../instructor/verification/day1-current.json), not historical fixed-motif benchmarks. The builder rejects a changed scientific/notebook source fingerprint until that notebook is rehearsed and its evidence refreshed. No model is run by the HTML. The [QA record](qa.md#full-day-1-implementation--2026-11-03) separates local verification from pending hosted Colab/classroom checks.

[Annotated outline](teaching-outline.md) preserves the instructor's comments byte-for-byte.
