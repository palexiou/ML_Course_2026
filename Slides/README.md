# Course presentations

Open [index.html](index.html) to choose a day. Each `Day_N/presentation.html` contains only that day's content, with inline code and font for offline viewing. Linked notebooks and teaching resources use the repository layout. Keep exported HTML beside its day's presentation for those links.

- Arrows, Space, Page Up/Down and swipe/wheel navigate; Home/End jump within the day. The slide selector jumps by title.
- Keys 1–4 or the day selector open another day. Stable hashes include `#day-1-slide-29`; the course index routes earlier day/global hashes.
- **N / Notes** opens explanations and transitions; Escape closes notes or editing. **E** edits text in the browser. **More → Save HTML** exports edits; **Print** prints the day's slides without notes. Reconcile accepted wording into repository source.

[Day 1 story](Day_1/story.md) is the active narrative-planning source. [Teaching preferences](../docs/course-wiki/teaching-preferences.md#style-approved--2026-11-03) is the style source. The [logistic style reference](Day_1/logistic-style-reference.html) demonstrates the approved clean progression; the full day decks retain their existing teaching design until section-by-section revision. Production designs omit repetitive visible “Illustrative example” labels while notes/source retain numerical provenance.
