# 08: Deliver the agent specification-and-audit experiment

**What to build:** A rehearsed, inspectable comparison of a vague agent request with an explicitly specified analysis supported by project instructions and a relevant scientific skill. Students can scientifically audit the resulting workflow whether they operate an agent or observe the instructor.

**Blocked by:** 02: Deliver the split-leakage investigation; 07: Make Day 3 classroom-ready and deliver the protected test comparison.

**Status:** ready-for-agent

- [ ] Prepare a vague sequence-classification question and an explicit analysis specification covering objective, inputs, split policy, metrics, constraints, outputs, and scientific responsibilities.
- [ ] Prepare project instructions and a relevant reusable scientific workflow skill whose role is distinguishable from the specification and the agent's tools.
- [ ] Run and record the comparison from clean demonstration contexts, identifying prior prompts, available data, model/tool conditions, and any differences that affect interpretation.
- [ ] Expose actual silent decisions, code, results, and interpretation for discussion. Do not require a stochastic live agent to reproduce a particular failure or portray instructions as a guarantee of scientific validity.
- [ ] Audit split integrity, preprocessing, metric selection, baseline comparison, reproducibility, and interpretation against known simulation truth and the manual workflows.
- [ ] Preserve the evaluation boundary: previously revealed Day 3 test results are demonstration evidence, not a fresh independent test for agent models tuned after that reveal.
- [ ] Deliver a readable one-page scientific-audit checklist and matching instructor audit answers grounded in the observed analyses; distinguish working code from valid inference.
- [ ] Provide optional student participation instructions when access exists and a complete observation route with the same evidence, decisions, and questions, without requiring paid access.
- [ ] Prepare clearly identified saved outputs and a short recorded agent run supporting the same audit questions when external services fail; distinguish contingency evidence from successful live verification.
- [ ] Rehearse the demonstration and audit portions within the approved Day 4 blocks and record execution costs, limitations, and any genuine account/tool blockers requiring instructor help.
