# Triage labels

Canonical triage roles map directly to local Status values:

- needs-triage: maintainer needs to evaluate the issue.
- needs-info: waiting for more information.
- ready-for-agent: fully specified and ready for agent work.
- ready-for-human: requires human implementation.
- wontfix: will not be actioned.

When a skill says to apply a triage label, update the local
Status line to the corresponding value.

Wayfinding tickets additionally use claimed and resolved
as described in the issue-tracker configuration.
